# PROUD CONTENT MACHINE

Локальная программа для Windows 11: загружаете бит, выбираете фрагмент, пишете название, выбираете от 1 до 3 визуальных шаблонов, настраиваете вид, смотрите предпросмотр и нажимаете **GENERATE**. На выходе готовые вертикальные MP4 (1080×1920, H.264 + AAC) под Reels, Shorts и TikTok.

Все файлы обрабатываются на вашем компьютере. Программа ничего не загружает в облако. Интернет нужен только один раз, при установке зависимостей.

## Установка и запуск

1. Установите Python 3.10 или новее с https://www.python.org/downloads/ . В установщике отметьте **Add python.exe to PATH** и не отключайте компонент **tcl/tk and IDLE**.
2. Дважды щёлкните **`install.bat`**. Он создаст папку `.venv`, поставит Pillow, NumPy и imageio-ffmpeg (вместе с ним приходит ffmpeg.exe) и проверит установку.
3. Запускайте программу файлом **`run.bat`**. Если установка не выполнялась, `run.bat` сам вызовет `install.bat`.

Папку проекта можно держать в любом месте, в том числе с пробелами и кириллицей в пути. Бит можно перетащить мышью на `run.bat`, и он откроется сразу.

## Как пользоваться

1. **Импорт.** `Ctrl+O` или кнопка «Импортировать бит». Поддерживаются MP3, WAV, FLAC, OGG, M4A, AAC, WMA, AIFF, OPUS.
2. **Фрагмент.** Тяните края выделения или весь фрагмент на волне. Можно ввести время вручную (`1:23.5` или `83.5`), нажать 15/30/45/60 с или «Лучший фрагмент» (самый энергичный участок). Длина от 1 до 180 секунд.
3. **Название** (обязательное) и необязательный подзаголовок. По умолчанию подставляется имя файла.
4. **Шаблоны.** Отметьте от одного до трёх: Neon Wave, Spectrum Bars, Minimal Type. На каждый шаблон будет отдельный файл.
5. **Визуал.** Палитра шаблона или свои цвета, фон (градиент, цвет, ваша картинка с затемнением), шрифт (в том числе свой файл), размер заголовка, чувствительность к звуку, свечение, полоса прогресса, анимация текста. Настройки можно сохранить как пресет и загрузить позже.
6. **Предпросмотр.** Справа живой кадр. Двигайте ползунок или нажмите «Играть» (пробел) — картинка и звук фрагмента.
7. **GENERATE** (`Ctrl+G`). Прогресс виден внизу, идущий экспорт можно отменить.
8. Файлы появятся в папке результата (по умолчанию `Видео\Proud Content Machine`) с именами вида `Название_neon_wave.mp4`. Существующие файлы никогда не перезаписываются: к имени добавляется `(2)`, `(3)`.

Настройки (разрешение 1080×1920 или 720×1280, FPS, качество, fade in/out, длина фрагмента по умолчанию, папка результата) находятся в меню **Файл → Настройки**. Они хранятся в `%APPDATA%\ProudContentMachine\settings.json`, лог в `%APPDATA%\ProudContentMachine\logs\pcm.log`.

## Структура проекта

```
pcm/                  пакет приложения
  audio.py            декодирование через FFmpeg, волна, лучший фрагмент, анализ спектра
  config.py           VisualConfig, JobConfig, валидация
  settings.py         настройки (атомарная запись, повреждённый файл не затирается)
  paths.py            имена файлов Windows, уникальные пути, время
  fonts.py            поиск шрифтов с кириллицей
  ffmpeg_tools.py     поиск FFmpeg
  renderer.py         кадры -> FFmpeg (pipe) -> MP4
  exporter.py         экспорт по шаблонам, отмена, очистка временных файлов
  session.py          состояние редактора без GUI (предпросмотр, выбор фрагмента)
  templates/          neon_wave, spectrum_bars, minimal_type + общая база
  gui/                окно на tkinter, волна, диалог настроек, тема
tests/                автоматические тесты (unittest)
install.bat  run.bat  run_tests.bat  requirements.txt
```

Новый шаблон добавляется классом-наследником `VisualTemplate` и записью в `pcm/templates/__init__.py`.

## Тесты

`run_tests.bat` (или `python -m unittest discover -s tests -v`). Тесты синтезируют аудио, декодируют его из пути с кириллицей и пробелами, рендерят все шаблоны, кодируют настоящие MP4 и проверяют их через FFmpeg (кодек, размер, длительность, звук). Логика окна проверяется на заглушке tkinter, поэтому настоящая отрисовка окна тестами не покрыта.

## Принятые технические решения

- **GUI на tkinter**, а не PySide6: он входит в стандартный Python для Windows, не требует тяжёлых зависимостей и ставится без сюрпризов.
- **FFmpeg через imageio-ffmpeg**: не нужно ничего скачивать вручную. Можно подложить свой `bin\ffmpeg.exe` или задать переменную `PCM_FFMPEG`.
- Кадры рисуются Pillow и NumPy, не зависят от разрешения (макет считается в долях), поэтому предпросмотр и итог выглядят одинаково.
- FFmpeg получает только ASCII-пути: видео сначала пишется во временную папку и затем переносится по итоговому пути с кириллицей. Если прямое чтение аудио по такому пути не сработало, используется временная копия.
- Текст держится вне зон интерфейса соцсетей: заголовок в верхней трети кадра, полоса прогресса выше нижней трети.
- Цвета видео размечены как BT.709, чтобы плееры не искажали палитру.

## Известные ограничения

- Предпросмотр со звуком работает только в Windows (через `winsound`), в предпросмотре звук всегда стартует с выбранной позиции, перемотка во время игры останавливает воспроизведение.
- Перетаскивание файла в окно программы не поддерживается (нужен сторонний пакет). Вместо этого есть импорт и перетаскивание на `run.bat`.
- Предпросмотр рисуется в уменьшенном размере 288×512, поэтому тонкие линии выглядят чуть иначе, чем в итоговом 1080×1920.
- Максимум 20 минут трека (остальное обрезается), фрагмент до 180 секунд.
- Фигуры рисуются без сглаживания краёв; свечение маскирует это на неоновых шаблонах, но у чётких линий Minimal Type края могут быть заметны при внимательном просмотре.
- Только вертикальный формат 9:16.
- Кодек H.264/AAC из imageio-ffmpeg. Аппаратное ускорение (NVENC и т. п.) не используется.

## Если что-то не работает

- «Не найден tkinter»: переустановите Python с python.org и оставьте включённым tcl/tk.
- Ошибка при установке зависимостей: проверьте интернет и повторите `install.bat`.
- Подробности любых ошибок: `%APPDATA%\ProudContentMachine\logs\pcm.log`.
